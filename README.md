# CINEMA Аниме Загрузочный Экран для Garry's Mod

Красивый аниме-стилизованный загрузочный экран для серверов Garry's Mod с режимом CINEMA - с эффектами и анимациями.

![Превью](preview.jpg)

## Особенности

- Стильный аниме-дизайн с тематикой CINEMA режима
- Множество анимированных элементов и визуальных эффектов:
  - Падающие лепестки сакуры
  - Градиентный текст с анимацией
  - Анимированные персонажи с эффектами свечения
  - Интерактивные элементы с эффектами при наведении
  - Анимированные уведомления и советы
- Динамический прогресс-бар загрузки с эффектами
- Цитаты из аниме с автоматической сменой
- Отображение информации о сервере и карте
- Удобное управление музыкой со слайдером громкости
- Циклические подсказки для игроков
- Фоновая музыка с визуальным контроллером
- Адаптивный и отзывчивый дизайн
- Социальные иконки с анимацией

## Установка

1. Скачайте и распакуйте содержимое архива в папку `garrysmod/` вашего сервера
2. Файлы должны быть расположены следующим образом:
   - `garrysmod/lua/autorun/client/cl_cinema_loadingscreen.lua`
   - `garrysmod/cinema_loadingscreen/index.html`
   - `garrysmod/cinema_loadingscreen/css/styles.css`
   - `garrysmod/cinema_loadingscreen/js/loading.js`
   - `garrysmod/cinema_loadingscreen/img/*` (изображения)
   - `garrysmod/cinema_loadingscreen/audio/*` (аудиофайлы)

3. Перезапустите сервер

> **Важно:** если вы используете внешний сайт (MyArena и т.д.), убедитесь, что в `lua/autorun/server/cinema_loading_server.lua` оставлено `ENABLE_LOCAL_THEME_ROTATION = false`. Иначе скрипт будет постоянно переписывать `sv_loadingurl` на локальные файлы `asset://...`, и клиенты увидят белый экран.

### Автопереключение по московскому времени

1. Закиньте файл `index.php` в ту же директорию, где лежат `index.html`, `index_dawn.html`, `index_sunset.html` и `index_night.html`.
2. В конфиге сервера или панели MyArena пропишите `sv_loadingurl "https://ваш-домен/index.php"`.
3. Скрипт сам выберет:
   - `index_night.html` c 00:00 до 05:59 (ночь)
   - `index_dawn.html` c 06:00 до 11:59 (утро)
   - `index.html` c 12:00 до 17:59 (день)
   - `index_sunset.html` c 18:00 до 23:59 (вечер)
4. Для ручной проверки можно открыть `https://ваш-домен/index.php?variant=night|dawn|day|sunset`.

## Настройка

### Изменение текста и настроек

Для изменения названия сервера, текста подсказок и других параметров, отредактируйте следующие файлы:

- Для изменения подсказок: `cinema_loadingscreen/js/loading.js` (массив `tips`)
- Для изменения аниме цитат: `cinema_loadingscreen/js/loading.js` (массив `animeQuotes`)
- Для изменения информации о сервере по умолчанию: `cinema_loadingscreen/index.html` (элементы с ID `serverName`, `mapName`, и т.д.)
- Для изменения социальных ссылок: `cinema_loadingscreen/index.html` (блок `social-icons`)

### Изменение цветов и стилей

Вы можете изменить основные цвета и внешний вид экрана, отредактировав переменные CSS в начале файла `cinema_loadingscreen/css/styles.css`:

```css
:root {
    --primary-color: #f1c40f;    /* Основной цвет (желтый) */
    --secondary-color: #e74c3c;  /* Вторичный цвет (красный) */
    --accent-color: #9b59b6;     /* Акцентный цвет (фиолетовый) */
    --dark-bg: #121212;          /* Цвет фона */
    --glow-color: rgba(241, 196, 15, 0.7); /* Цвет свечения основного цвета */
    --glow-purple: rgba(155, 89, 182, 0.7); /* Цвет свечения акцентного цвета */
}
```

### Изменение изображений

Для изменения фоновых изображений и персонажей:

1. Поместите ваши собственные изображения в папку `cinema_loadingscreen/img/`
2. Рекомендуемые размеры:
   - Фоновое изображение: 1920×1080px
   - Логотип: 200×200px
   - Аниме персонажи: высота ~700px, PNG с прозрачностью
   - Лепесток сакуры: ~50x50px, PNG с прозрачностью

### Изменение музыки

1. Поместите вашу фоновую музыку в папку `cinema_loadingscreen/audio/`
2. Убедитесь, что файл называется `background.mp3` или обновите путь в `index.html`

## Проблемы и решения

**Музыка не воспроизводится автоматически:**
Это нормально из-за политик современных браузеров. Игрок может нажать на кнопку включения музыки.

**Изображения не отображаются:**
Проверьте пути к файлам и убедитесь, что изображения загружены на сервер.

**Эффекты работают медленно:**
Можно уменьшить количество лепестков сакуры, изменив переменную `sakuraCount` в `loading.js`.

## Подключение информации о игроке

Для отображения информации об игроке на загрузочном экране используется Steam Web API.

### Получение Steam Web API ключа

1. Зайдите на страницу [Steam Web API Key](https://steamcommunity.com/dev/apikey)
2. Авторизуйтесь через свой Steam аккаунт
3. Введите домен (можно указать IP сервера или любой домен)
4. Нажмите "Register" и получите API ключ

### Настройка API ключа

1. Откройте файл `lua/autorun/client/cl_cinema_loadingscreen.lua`
2. Найдите строку `local STEAM_API_KEY = "YOUR_STEAM_API_KEY"`
3. Замените `YOUR_STEAM_API_KEY` на ваш полученный API ключ
4. Сохраните файл

```lua
-- Пример
local STEAM_API_KEY = "A1B2C3D4E5F6G7H8I9J0K1L2M3N4O5P6" -- Ваш Steam Web API ключ
```

### Информация о игроке

После настройки API ключа, загрузочный экран будет автоматически отображать следующую информацию:

- Аватар игрока (загружается из Steam)
- Имя игрока
- Время игры на сервере
- Дата последнего визита
- Ранг игрока
- Уровень игрока

Если API ключ не указан, будет использоваться стандартный аватар и информация, доступная на сервере.

# Инструкция по установке и настройке системы синхронизации Garry's Mod с загрузочным экраном

Данная система позволяет отображать на загрузочном экране актуальную информацию о сервере, включая количество игроков.

## Структура файлов

- `lua/autorun/server/cinema_loading_server.lua` - серверная часть для Garry's Mod
- `lua/autorun/client/cinema_loading_client.lua` - клиентская часть для Garry's Mod
- `js/loading.js` - JavaScript для загрузочного экрана (уже обновлен с функциями синхронизации)
- `php/server_api.php` - API для взаимодействия между сервером и загрузочным экраном
- `php/create_table.sql` - SQL скрипт для создания таблицы в базе данных

## Установка

### Шаг 1: Настройка загрузочного экрана

1. В файле `js/loading.js` уже добавлены необходимые функции:
   - `SetPlayerCount` - для прямого обновления количества игроков
   - `fetchServerInfoFromWebsite` - для получения информации с веб-сервера

2. Замените URL в функции `fetchServerInfoFromWebsite`:
   ```javascript
   const apiUrl = 'https://ваш-сайт.ru/server_api.php';
   ```
   на фактический URL вашего API.

### Шаг 2: Настройка серверной части Garry's Mod

1. Скопируйте содержимое папки `lua` в папку `lua` на вашем сервере Garry's Mod.
   - Файл `cinema_loading_server.lua` должен находиться в `lua/autorun/server/`
   - Файл `cinema_loading_client.lua` должен находиться в `lua/autorun/client/`

2. Если вы хотите отправлять данные на внешний веб-сервер, отредактируйте файл `lua/autorun/server/cinema_loading_server.lua`:
   - Раскомментируйте блок кода в функции `SendInfoToWebsite`
   - Замените `"https://ваш-сайт.ru/server_api.php"` на URL вашего API
   - Раскомментируйте строку `timer.Create("CINEMA_SendInfoToWebsite", 60, 0, SendInfoToWebsite)`
   - Замените `"cinema_secure_key"` на ваш секретный ключ API (такой же, как в `server_api.php`)

### Шаг 3: Настройка веб-сервера (по желанию)

Если вы хотите использовать API для получения информации о сервере через веб-сайт:

1. Создайте базу данных на вашем хостинге:
   ```sql
   CREATE DATABASE cinema_server;
   ```

2. Загрузите и выполните SQL-скрипт `php/create_table.sql` для создания таблицы:
   ```
   mysql -u username -p cinema_server < create_table.sql
   ```

3. Загрузите файл `php/server_api.php` на ваш веб-сервер и отредактируйте настройки подключения к базе данных:
   ```php
   $db_config = [
       'host' => 'localhost',
       'dbname' => 'cinema_server', 
       'username' => 'root',
       'password' => '',
       'charset' => 'utf8mb4'
   ];
   ```

4. Измените секретный ключ API на безопасный:
   ```php
   $api_secret_key = 'ваш_безопасный_ключ';
   ```

## Проверка работоспособности

1. **Прямая передача данных от сервера Garry's Mod к загрузочному экрану:**
   - Подключитесь к серверу Garry's Mod
   - На экране загрузки вы должны увидеть актуальное количество игроков вместо "?"

2. **Получение данных через API (если настроен):**
   - Перейдите по адресу `https://ваш-сайт.ru/server_api.php`
   - Вы должны увидеть JSON с информацией о сервере

## Устранение неполадок

1. **Ошибки в консоли сервера Garry's Mod:**
   - Проверьте лог-файлы сервера на наличие ошибок, связанных с `cinema_loading_server.lua`
   - Убедитесь, что используемые хуки не конфликтуют с другими аддонами

2. **Загрузочный экран не получает данные:**
   - Откройте консоль браузера (F12) и проверьте наличие ошибок
   - Убедитесь, что функция `SetPlayerCount` определена в `loading.js`
   - Проверьте, работает ли хук `UpdateLoadingScreenPlayerCount` в `cinema_loading_client.lua`

3. **API не возвращает данные:**
   - Проверьте настройки подключения к базе данных
   - Убедитесь, что таблица `gmod_server_stats` создана и содержит данные
   - Проверьте права доступа к файлу `server_api.php` и базе данных
